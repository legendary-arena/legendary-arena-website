# Diorama Master Plan — moved to the `legendary-forge` repo

**This document has moved.** The diorama is now developed as a standalone venture
in its own private repository, **`legendary-forge`**, kept separate from this
marketing repo so it can be transferred or sold as its own asset.

- **Canonical product spec (current):** `legendary-forge` → `docs/master-plan.md`
  — the **V2 plug-and-play** architecture (magnetic Lite-Brite grid, the labeled
  "Smart Hub", sealed no-code motion modules, Bluetooth audio) that supersedes the
  original Raspberry Pi / code-it-yourself plan.
- **Original V1 plan:** preserved at `legendary-forge` → `docs/master-plan-v1-archive.md`
  (full mechanism library, prototype BOM, and aquarium engineering).

Repo: https://github.com/barefootbetters/legendary-forge (private)

## Why this moved

The full build/engineering IP — components, business model, BOM, STEM curriculum,
and the mechanism library — is the venture's core asset. Housing it in
`legendary-forge` rather than this Legendary Arena marketing repo means the
diorama line can change hands without untangling it from this repo's git history.

## What stays in this repo

This marketing repo still **sells** the diorama: the waitlist / commerce page at
`legendary-arena.com/diorama` ([`content/diorama/_index.md`](../../content/diorama/_index.md))
and its product image stay here, riding Legendary Arena's audience. Only the
product *spec* moved — selling through the marketing site is intentional and does
not re-couple the IP.
