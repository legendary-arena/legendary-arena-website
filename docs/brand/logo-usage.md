# Legendary Arena — Logo Usage Guidelines

**Status:** Active
**Last updated:** 2026-09-04

> **Authority:** subordinate to `docs/brand/strategy.md`,
> `docs/brand/palette.md`, and `docs/brand/typography.md`. This document
> governs how the **approved split emblem** identity (adopted in WP-247) is
> used. It supersedes the logo-usage guidance in `logo-brief.md`, which
> described the deferred effort this identity fulfils.

The mark is a single emblem split down the centre: a **gold winged sword**
(the hero) mirrored against a **white bone-and-horn mark** (the villain).
Gold-led, symmetric, heroic — the brand made visible.

## 1. The marks

| Mark | File | Use |
|---|---|---|
| Primary lockup | `logo-la-lockup.svg` | Default identity where there is horizontal room: headers, press, heroes. |
| Emblem | `logo-la-emblem.svg` | Standalone mark: favicon, avatar, app icon, HUD badge. |
| Wordmark | `logo-la-wordmark.svg` | Text-only lockups, or where the emblem appears separately. |
| Monochrome | `logo-la-emblem-mono.svg` | Single ink — merch, emboss, watermark, and **all light surfaces**. |
| Gold hero half | `logo-la-hero-gold.png` | Optional single-side accent. |

All live in `static/brand/logo/`. The editable master is
`Legendary Arena-400x200.ai` in the brand asset store (not in this repo).

## 2. Clear space

Keep a minimum clear space equal to **X = half the mark's height** on all
four sides, free of other logos, text, or busy imagery.

![Clear-space rule: the lockup inside a dashed exclusion zone set X (half the mark height) from every edge.](/brand/logo/guide-clearspace.png)

## 3. Minimum size

Below these sizes the mark loses legibility — step up a mark instead (e.g.
use the emblem where the lockup would be too small).

![Minimum sizes: the emblem at 24 px, the lockup at 120 px wide.](/brand/logo/guide-minsize.png)

| Mark | Minimum |
|---|---|
| Emblem | 24 px (favicon-safe) |
| Lockup | 120 px wide |
| Wordmark | 100 px wide |

## 4. Light / dark pairing (the mark is a dark-surface identity)

The white villain half is drawn against the deep-navy ground. On light
surfaces the full-colour emblem loses that half, so it must not be used
there — the monochrome mark is the light-surface answer.

| Surface | Use | Do not use |
|---|---|---|
| Dark (`#0b0f19` and near-black) | Full-colour emblem / lockup / wordmark | — |
| Light (`#fdfcf8` and near-white) | **Monochrome** emblem/lockup (single ink) | Full-colour emblem (villain half disappears) |
| Photographic / busy | Mark on a solid dark plate | Mark placed directly on the image |

## 5. Do / don't

**Do**
- Place the full-colour mark on the dark ground it is designed for.
- Use the monochrome master on light surfaces and for single-ink work.
- Keep the clear space and minimum sizes above.
- Scale proportionally.

**Don't**
- Recolor the emblem or restyle its gold gradient (the monochrome master is
  the *only* sanctioned single-ink recolor).
- Add drop shadows, outer glows, bevels, or other effects beyond the master.
- Put the full-colour emblem on a light or busy background.
- Stretch, squash, rotate, or otherwise distort the proportions.
- Apply class colors (`--la-color-class-*`) — those signal gameplay role,
  not brand identity (see `palette.md` §4.4).

## 6. Color and type

Color and type come from the token system, not from this document:

- Golds: `--la-color-gold` / `--la-color-gold-bright` (`#b8901f`/`#d4af37`
  light, `#d4af37`/`#f0c94a` dark) — canonical in `brand-tokens.css`.
- Display face: **Bebas Neue** (the wordmark's letterforms).

If this document and `brand-tokens.css` disagree, the CSS wins.

## 7. Regeneration

The emblem's derived assets (monochrome, favicons, mask, maskable) are
generated from `logo-la-emblem.svg` by `scripts/build-brand-icons.py`. The
guideline diagrams here are generated by `scripts/build-brand-guides.py`.
Both are idempotent — re-run after any change to the emblem master.
